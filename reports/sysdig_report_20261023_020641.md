### [Critical] Sysdig Host Shield for Linux リリースノート

**概要:**
Sysdig Host Shield for Linuxの最新リリースノートでは、重要な非推奨（Deprecation）情報と、バグ修正、脆弱性修正が含まれています。特に、Legacy eBPFとSecure Modeのサポート終了が近づいているため、早急な対応が必要です。

**詳細:**
- **非推奨情報（Deprecation Notice）:**
  - Legacy eBPFはバージョン14.3.0から非推奨となり、2026年12月4日以降サポートされません。今後のリリースでは新機能が追加されません。
  - Secure Modeも同様に2026年12月4日にサポート終了となります。Secure_Lightモードへの移行が推奨されます。
- **バージョン14.8.2（2026年10月21日）:**
  - サポートされるシールドチャートバージョンは1.54.5です。
  - バグ修正と脆弱性修正が含まれていますが、具体的な内容は記載されていません。
- **バージョン14.8.1（2026年10月8日）:**
  - 機能強化、バグ修正、脆弱性修正が含まれています。
- **バージョン14.8.0（2026年9月24日）:**
  - 機能強化が行われています。

**お客様への影響:**
- Legacy eBPFとSecure Modeのサポート終了により、これらを使用しているシステムは今後のアップデートで新機能やセキュリティパッチを受け取れなくなります。
- サポート終了後は、セキュリティリスクが増大する可能性があります。

**推奨アクション:**
- Legacy eBPFを使用している場合は、Universal eBPFまたはKernel Moduleへの移行を検討してください。特に、カーネルバージョンが5.8より古い環境ではKernel Moduleが推奨されます。
- Secure Modeを使用している場合は、Secure_Lightモードへの移行を行ってください。これにより、パフォーマンスの向上と長期的なサポートが得られます。
- 詳細な移行手順については、Sysdigのドライバードキュメントを参照してください。
