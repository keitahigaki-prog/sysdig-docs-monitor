### [Critical] Sysdig Host Shield for Linux リリースノート

**概要:**
Sysdig Host Shield for Linuxの最新リリースノートでは、重要な機能の非推奨（Deprecation）とサポート終了（EOL）に関する情報が含まれています。特に、Legacy eBPFとSecure Modeのサポート終了が発表されており、これらの機能を使用しているお客様は早急な対応が必要です。

**詳細:**
- **Legacy eBPFの非推奨**: バージョン14.3.0以降、Legacy eBPFは非推奨となり、2026年12月4日以降はサポートされません。今後のリリースでは新機能が追加されないため、Universal eBPFまたはKernel Moduleへの移行が推奨されます。
- **Secure Modeの非推奨**: Secure Modeは2026年12月4日に完全に廃止されます。これに代わり、Secure_Lightモードへの移行が推奨されており、こちらは長期的にサポートされるオプションです。

**お客様への影響:**
- Legacy eBPFを使用している場合、サポート終了後は新機能の利用ができなくなり、セキュリティリスクが増大する可能性があります。
- Secure Modeを使用している場合、サポート終了後はパフォーマンスの向上やセキュリティの強化が受けられなくなります。

**推奨アクション:**
- **Legacy eBPFを使用しているお客様**: 2026年12月4日までにUniversal eBPFまたはKernel Moduleに移行してください。詳細はドライバードキュメントを参照してください。
- **Secure Modeを使用しているお客様**: Secure_Lightモードに移行し、引き続きサポートとパフォーマンスの向上を受けられるようにしてください。移行手順については、非推奨ポリシーを参照してください。
